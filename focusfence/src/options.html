    Strict mode

    For when willpower runs out. While strict mode is on, blocking can't be turned off, sites can't be removed and the schedule can't be changed. Ending early takes a 10-minute cooling-off period and a typing challenge.

    Incognito windows are not blocked

    FocusFence isn't allowed in Incognito, so a private window skips your blocklist — even in strict mode. Turn on Allow in Incognito in FocusFence's extension details.

    STRICT MODE ON

    What strict mode can't prevent
    • Chrome lets you disable or remove any extension from chrome://extensions. FocusFence can't block that page. A timed strict session pauses while FocusFence is off, so its time can't run out in the background.
    • Incognito windows are only covered if you allow FocusFence in Incognito (see above).
    • Other browsers, other Chrome profiles and other devices aren't covered.

    Password lock

    Require a password to turn blocking off, remove sites or change settings. Ideal if someone else holds the key. Passwords are hashed (PBKDF2) and never leave this device.

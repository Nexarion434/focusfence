## Ground rules for every channel

1. **Honesty first.** Only claim what the extension does today. Path and keyword blocking, schedules, Pomodoro, strict mode, password lock and stats are **Pro**. Free covers unlimited domain blocking.
2. **Disclose.** Always say you built FocusFence.
3. **Limits are a feature of trust.** Mention that strict mode can't stop someone from disabling the extension in `chrome://extensions`.
4. **No fake reviews, no vote rings, no asking friends to upvote.** This breaks Product Hunt's and Reddit's rules.
5. **Links:** use the Chrome Web Store link once it exists (`STORE_URL` in `focusfence/scripts/docs.mjs`). Until then, there is nothing to link to.

## Reddit rules: what was and wasn't verified

The subreddit rule pages couldn't be fetched while drafting (reddit.com blocks automated access), so the drafts follow Reddit's site-wide self-promotion guidance:
- about 90% of your activity should be genuine participation, at most 10% self-promotion;
- each subreddit's moderators set their own rules on top of that.

Mirror pages suggest r/getdisciplined requires a tag in the title and treats more than 10% self-related content as spam. **Check both subreddits' current sidebar and wiki before posting.**
